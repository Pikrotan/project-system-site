Privacy Policy

Last updated: September 21, 2026

Google Workspace access

Project System uses the Google Drive API with the drive.file scope. This allows the application to access Google Drive files that it creates or that the user explicitly authorizes for use with the application.

How data is used

Google Workspace data is used only to provide Project System functionality, including synchronization of project overview documents, design knowledge, and design change records.

OAuth credentials

OAuth tokens and client configuration are stored locally on the user's computer using protected operating-system storage. They are not stored in the Project System Git repository.

Data sharing

Project System does not sell Google user data and does not use Google user data for advertising.

Data retention

Project System does not operate a separate cloud database for Google Workspace content. Project data remains in the user's Google Workspace and local project environment.

Revoking access

Users can revoke Project System's Google account access through their Google Account security settings.
